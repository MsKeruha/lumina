# Lumina Reading Club 📚✨

**Lumina** — це передова інтелектуальна SPA-платформа для книжкових клубів, розроблена як випускна кваліфікаційна робота. Додаток поєднує у собі елементи соціальної мережі, гейміфікований літературний трекер та рекомендаційну систему на базі алгоритмів аналізу тексту.

---

## ✨ Ключові можливості та модулі

### 🧠 1. Інтелектуальні рекомендації (AI Engine)
* Реалізовано автономну рекомендаційну систему на основі контенту (**Content-Based Recommendation**).
* Використовується алгоритм перетину множин тегів (**Overlap Coefficient / Jaccard Similarity**) з додатковим ваговим коефіцієнтом категоріальної приналежності.
* Система автоматично ранжує та пропонує 5 найбільш тематично близьких видань під час перегляду будь-якої книги.

### 🏆 2. Гейміфікована система динамічних досягнень (Rules Engine)
* Унікальний **математичний інтерпретатор Python-виразів** на бэкенді.
* **Повна підтримка логіки:** можливість створювати як накопичувальні формули (наприклад, `books_read * 100 + pages_read`), так і складні булеві умови з використанням логічних операторів (`and`, `or`, порівняння `>` / `<`).
* Автоматичний маппінг логічних результатів `True/False` у 100% або 0% прогресу нагороди.

### 🛡️ 3. Модуль кібербезпеки (Sandbox Parser)
* Всі кастомні формули адмінів проходять строгу **RegExp-перевірку** на відсутність сторонніх символів.
* Виконання обчислень в ізольованій песочниці `eval()` із заблокованим доступом до `__builtins__` та системних бібліотек.
* Механізм **Dry Run** (тестовий прогін) валідує синтаксис формули на етапі створення, запобігаючи потраплянню помилкових виразів у БД.

### 👥 4. Соціальна мережа та Інтерактив
* **Публічні профілі:** Перегляд статистики інших користувачів, їхніх відкритих трофеїв та прогресу літературних щоденників.
* **Книжкові клуби:** Керування куратором, живі обговорення з миттєвим коментуванням.
* **Модуль голосувань (Polls):** Вибір книг для майбутніх читань з візуалізацією результатів у реальному часі.

## 🚀 Швидкий старт

### 🐳 Запуск через Docker Compose (рекомендовано)

Для підняття всієї інфраструктури (БД + FastAPI + React) однією командою:

```bash
docker-compose up --build
```

**Порти після запуску:**
* 🌐 Frontend SPA: `http://localhost:80` (або просто `http://localhost`)
* ⚙️ Backend API Docs (Swagger): `http://localhost:8000/docs`
* 🐘 База даних: `postgresql://localhost:5432`

> [!NOTE]
> **Ідемпотентність Сидера:** Під час кожного запуску контейнера автоматично виконується скрипт `backend/scripts/seed.py`. Завдяки вбудованим перевіркам `if not exists:` повторний запуск є безпечним — він оновлює тільки відсутні дані, не дублюючи існуючі записи.

### 👨‍💻 Локальна розробка

#### Backend:
1. Встановіть залежності: `pip install -r requirements.txt`
2. Запустіть міграції: `alembic upgrade head`
3. Запуск dev-сервера: `python -m uvicorn app.main:app --reload --port 8000`

#### Frontend:
1. Встановіть Node-пакети: `npm install`
2. Запустіть збірку: `npm run dev`

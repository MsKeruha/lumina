# Lumina Reading Club 📚

**Lumina** — це сучасна платформа для книжкових клубів, розроблена як дипломний проект. Платформа дозволяє користувачам об'єднуватися в спільноти, обговорювати книги та вести персональний літературний щоденник.

## ✨ Основні можливості

- **Автентифікація**: Безпечний вхід та реєстрація за допомогою JWT-токенів.
- **Бібліотека**: Перегляд та пошук книг за назвою, автором та категорією.
- **Книжкові Клуби**: Створення власних клубів та приєднання до існуючих.
- **Обговорення**: Кожен клуб має дискусії по конкретним книгам з можливістю коментування в реальному часі.
- **Профіль користувача**: Персоналізація профілю (аватар, біографія).
- **Панель Адміністратора**: Управління контентом платформи та перегляд статистики.

## 🛠 Технологічний стек

### Backend
- **FastAPI**: Сучасний та швидкий веб-фреймворк для Python.
- **SQLAlchemy**: Потужна ORM для взаємодії з базою даних.
- **PostgreSQL**: Надійна реляційна база даних.
- **Alembic**: Система міграцій бази даних.
- **Pydantic**: Валідація даних та схеми API.

### Frontend
- **React**: Бібліотека для створення користувацьких інтерфейсів.
- **Vite**: Швидкий інструмент збірки.
- **React Router**: Навігація в Single Page Application.
- **Lucide React**: Сучасні іконки.
- **Glassmorphism UI**: Преміальний дизайн з ефектами розмиття та прозорості.

## 🚀 Швидкий старт

### Використання Docker (рекомендовано)

Для запуску всього стеку однією командою:

```bash
docker-compose up --build
```

Після запуску:
- Frontend: `http://localhost`
- Backend API: `http://localhost:8000`
- API Документація: `http://localhost:8000/docs`

### Локальна розробка

#### Backend
1. Перейдіть в директорію `backend`.
2. Встановіть залежності: `pip install -r requirements.txt`.
3. Запустіть сервер: `python -m uvicorn app.main:app --reload`.

#### Frontend
1. Перейдіть в директорію `frontend`.
2. Встановіть залежності: `npm install`.
3. Запустіть в режимі розробки: `npm run dev`.

## 🏗 Архітектура проекту

Проект реалізовано за модульною архітектурою:
- `backend/app/routers/` — розділення логіки API на тематичні модулі (auth, books, clubs, users, admin).
- `backend/app/models.py` — описує структуру бази даних.
- `frontend/src/context/` — глобальне управління станом (AuthContext).
- `frontend/src/pages/` — окремі сторінки додатку.

## 🛡 Безпека

- Паролі хешуються за допомогою `bcrypt`.
- Ролевий доступ (RBAC): звичайні користувачі та адміністратори.
- Валідація вхідних даних на рівні схем Pydantic.
